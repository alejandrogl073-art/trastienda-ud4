# La Trastienda · UD4 4.1 Fundamentos CSS

Ejercicio propuesto del tema 4.1: estructura semántica y primeros estilos de la app de ejemplo «La Trastienda».

```
trastienda-ud4/
├── index.html      pantalla Home
├── carrito.html    pantalla Carrito
├── css/
│   └── estilos.css
└── img/
```

- HTML semántico (`header`, `main`, `section`, `article`, `nav`), un único `h1` y sin saltos de nivel.
- Botones de solo icono con `aria-label`; `aria-current="page"` en la pestaña activa.
- Resumen del carrito con `<dl>`; «Tramitar pedido» es un enlace porque lleva a otra pantalla.
- Una hoja externa común a las dos pantallas.
- Validado en el W3C: 0 errores.

Para verlo: abre la carpeta en VS Code y usa Live Server, en modo dispositivo a 393 × 852.
